Key Vocabulary

  • DNSDomain Name SystemTranslates website names into IP addresses — the Internet's phone book.
  • HTTPHyperText Transfer ProtocolThe rules for requesting and delivering web pages.
  • Digital DivideThe gap between people with good Internet access and those without.
  • Net NeutralityThe idea that providers should treat all websites equally.
How It Works

How Your Browser Finds a Website

When you type a website NAME, DNS looks up its IP number, then HTTP fetches the page. Here's what happens in order:

  1. You type a website name (like a store name you say out loud).
  2. Your device asks DNS, “What's the number for this name?”
  3. DNS returns the IP address — the site's real number.
  4. Your browser sends an HTTP request to that IP address.
  5. The server sends the page back, and it loads on your screen.
