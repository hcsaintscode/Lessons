Build an App with Lovable

Unit Project Guide · Problem Solving & Computing
Unit Project

Your Mission

You'll design and build a real app that solves a problem you care about — and put it online to share. First you PLAN it on paper (using everything you learned in this unit). Then you build it with lovable.dev, an AI that builds the app from your description.

DPTR IOSP Plan → Build → Share
⚠ Heads up on credits lovable's free plan gives about 5 build messages per day. Plan everything here on paper FIRST so you don't waste them. One clear description beats ten vague ones.

Step 3 · The Description

Write Your Build Prompt

Turn your IOSP spec into ONE clear description for lovable. Here's the shape:

Example — Water Tracker Build a simple water-tracker web app. INPUT: a button to add a glass of water, and a daily goal the user sets. OUTPUT: glasses today and a progress bar. STORAGE: remember today's count. PROCESSING: compare the count to the goal and show a cheer when it's reached. Make it colorful and simple.
