Think About It

  • A calculator only calculates. A typewriter only types.
  • Why can one laptop be a calculator, a synth, and a game — all at once?
It's programmable.

A Computer Is...

A programmable machine that processes information.
Every program has the same shape → IOSP

IOSP as a System Model

01 · INPUT
Data In
Data flows into the system.
02 · PROCESSING
Transform It
Turn the input into a result.
03 · OUTPUT
Results Out
Send the result back out.
04 · STORAGE
Remember It
Keep data between runs.

Input

Data that flows into the system.
form fields · sensors · files · other programs

Processing

Transforming input into output — where the problem is actually solved.

...and in code

  • If/Then if (age >= 13) { show(); }
  • Comparing if (score > best) { best = score; }
  • Finding a Match list.find(x => x === target)
  • Counting count = count + 1;

Output

The results the system produces.
text on screen · a rendered list · a sound · a file

Storage

Data the system remembers between runs.
saved games · user settings · history · localStorage
