What Is a Computer?

Week 2 Student Worksheet · Problem Solving & Computing · High School
Reference

Key Vocabulary

  • ComputerA programmable machine that processes information.
  • InputThe information a computer takes in.
  • OutputThe information a computer produces.
  • ProcessingThe work of turning input into output.
  • StorageSaving information so it can be used later.

Four Kinds of Processing

Almost every program is built from these four moves. Each one maps directly to code:

  • If / ThenMaking a decision.  if (age >= 13) { show(); }
  • ComparingChecking two values against each other.  if (score > best) { best = score; }
  • Finding a MatchSearching data for something that fits.  list.find(x => x === target)
  • CountingKeeping a running total.  count = count + 1;

Activity 3 · Build It

Build It (StackBlitz)

Open StackBlitz. Start from the Study Break Picker reference app (in your self-study module), run it, then change it into your app. Keep scope small: a few inputs, one processing step, one output.

Reference code — the Study Break Picker. Use it as your starting point.

index.html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Study Break Picker</title>
</head>
<body>
  <h1>Study Break Picker</h1>

  <label>How much time?
    <select id="time">
      <option value="5">5 minutes</option>
      <option value="15">15 minutes</option>
      <option value="30">30 minutes</option>
    </select>
  </label>

  <label>Energy level?
    <select id="energy">
      <option value="low">Low</option>
      <option value="high">High</option>
    </select>
  </label>

  <button id="go">Pick my break</button>
  <p id="result"></p>

  <script src="index.js"></script>
</body>
</html>
index.js
// INPUT: read the two dropdowns when the button is clicked
document.getElementById("go").addEventListener("click", function () {
  var minutes = Number(document.getElementById("time").value);
  var energy = document.getElementById("energy").value;

  // PROCESSING: if/then + comparing to pick a break
  var idea;
  if (energy === "high" && minutes >= 30) {
    idea = "Go for a walk outside.";
  } else if (energy === "high") {
    idea = "Do 20 jumping jacks.";
  } else if (minutes >= 15) {
    idea = "Rest your eyes and stretch.";
  } else {
    idea = "Drink some water and stretch.";
  }

  // OUTPUT: write the result to the page
  document.getElementById("result").textContent = idea;
});
