Lesson 1

A Programmable Machine

A computer is a programmable machine that processes information. A calculator only calculates; a typewriter only types. A computer is different because it can be reprogrammed to do almost any job you can describe precisely.

And no matter the job, every program has the same shape — four parts we call IOSP.

Lesson 2

IOSP — The Shape of Every Program

Input — data in

Data that flows into the system: form fields, sensors, files, or another program.

Processing — transform it

The work that turns input into output. This is where the problem actually gets solved.

Output — results out

The results the system produces: text on screen, a rendered list, a sound, a file.

Storage — remember it

Data the system keeps between runs: settings, history, saved progress.

Input → Processing (+ Storage) → Output. Model a problem in these four parts and you've written your code outline. That's what you'll do next.

Lesson 3

Processing, in Code

"Processing" is built from four simple moves — and each maps straight to JavaScript:

  • If / Then  if (age >= 13) { show(); }
  • Comparing  if (score > best) { best = score; }
  • Finding a Match  list.find(x => x === target)
  • Counting  count = count + 1;

The app in your editor uses If/Then and Comparing to pick a study break. Find those lines in index.js.

Try It · Part 2

Make It Yours

Now change the code on the right. Start small — each of these is a real edit developers make every day:

  • Change an output: edit one of the suggestion strings in index.js.
  • Add an input option: add <option value="60">60 minutes</option> to the time dropdown in index.html.
  • Add processing: add another else if branch for your new option.
Stuck? See an example edit

Add a 60-minute option in index.html:

<option value="60">60 minutes</option>

Then handle it in index.js — put this as the first branch inside the click handler:

if (energy === "high" && minutes >= 60) {
  idea = "Take a proper workout break.";
} else if (energy === "high" && minutes >= 30) {
  idea = "Go for a walk outside.";
}

Save, then pick 60 minutes + High energy in the preview to see your new branch run.

Stretch · Storage

Remember the Last Result

Right now the app forgets everything when it reloads — it has no Storage. Add two lines to give it memory using localStorage.

save the result (end of the click handler)
localStorage.setItem("lastIdea", idea);
show it again on load (top of index.js)
document.getElementById("result").textContent =
  localStorage.getItem("lastIdea") || "";

Now reload the preview — your last suggestion is still there. That's the S in IOSP.
