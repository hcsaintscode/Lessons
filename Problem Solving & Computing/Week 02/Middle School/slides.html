A Computer Is...

A machine that works with information.
Everything it does is one of four things →

The Four Things Every Computer Does

01
Input
The information it gets.
02
Output
The information it gives.
03

The information it saves.
04
Processing
The thinking work.

Input

The information a computer gets — from users, devices, or other computers.
touchscreen · microphone · camera · keyboard

Output

The information a computer gives back.
screen · speaker · vibration · printout

Processing

The "thinking work" that turns input into output.

Four Kinds of Processing

  • If/Then — if something is true, do something.
  • Comparing — is one bigger or the same?
  • Finding a Match — search a list.
  • Counting — keep track of how many.

Storage

Saving information to use in the future.
photos · high scores · your login · saved games

Putting It Together

Input → Processing (+ Storage) → Output. That loop is every app you've ever used.
INPUT → PROCESSING → OUTPUT
