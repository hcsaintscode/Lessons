A Function Is a Reusable Recipe

Package steps once, then CALL them by name whenever you need them.
function updateScore() {   score = score + 1;   setText("scoreLabel", score); }

Define Once, Call Anytime

updateScore();
Write the recipe once; call it from any button. No copy-paste.

Why Functions?

  • Less repeated code
  • Fix it in ONE place
  • Easier to read
Every app you use is built from functions.

Randomness Makes It Fun

var n = randomNumber(0, 255);
Random colors, random questions — that's what makes a game feel alive.
