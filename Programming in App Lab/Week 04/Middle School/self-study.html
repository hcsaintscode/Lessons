Lesson 1

Functions Are Reusable Recipes

A function is a named recipe for a job. You define it once, then call it by name anytime you need that job done — even a hundred times. Without functions, you'd copy the same steps over and over; with them, you write the steps in one place.

That means less repeated code, and when something needs to change, there's one place to fix instead of ten. Fix the recipe, and every call to it gets the fix for free.

Define — write the recipe once

function sayHi() { ... } creates the recipe. It doesn't run yet — it's just written down, ready to use.

Call It — run it by name

sayHi(); runs the recipe. The () means "do it now."

Reuse — use it anywhere

Call the same function from a button click, another function, or ten different spots — one recipe, used everywhere.

Define once, call by name
function sayHi() {
  console.log("Hi there!");
}

sayHi();   // runs the recipe
sayHi();   // runs it again — no copy-paste needed

Define the steps once inside the function; then each sayHi() re-runs them. Change the message in one place and every call updates.

Lesson 2

Everything Together

Look at everything you've built up over this unit — each piece does one job, and together they make a real app:

  • Events let the app react — a click, a tap, a keypress.
  • Variables let it remember — a name, a score, a count.
  • Conditionals let it decide — if this, then that.
  • Functions let it reuse — package a job and call it anytime.

Put them together and you don't have four separate ideas anymore — you have a real app. That's the whole point of the capstone.

Make It Yours

Make It Yours

Now make the Lucky Color app yours. You decide the colors it can pick and how it looks:

  • Add your own color: add a new { name: "...", value: "..." } to the colors list the function picks from.
  • Change the button label: edit the text inside the <button> in index.html.
  • Stretch: add a SECOND button that resets the counter back to 0.
Stuck? example edit

Add your own color to the colors list in index.js:

var colors = [
  { name: "Sunset Orange", value: "#e8553d" },
  { name: "Teal", value: "#2bb5a0" },
  { name: "Royal Purple", value: "#2d1b69" },
  { name: "Sunshine", value: "#f4c430" },
  { name: "My Blue", value: "#2b7ab5" }   // your color!
];

For the stretch, add a reset button in index.html:

<button id="resetBtn">Reset counter</button>

Then wire it up in index.js:

document.getElementById("resetBtn").addEventListener("click", function () {
  count = 0;
  document.getElementById("count").textContent = count;
});

New color in the list, a new button and its handler — the app now does more, and you decided what.
