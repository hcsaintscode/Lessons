Reference

Key Vocabulary

  • FunctionA named, reusable block of code you can call whenever you need it.
  • ParameterAn input a function takes so it can vary its behavior each time it runs.
  • ArgumentThe actual value you pass in when calling the function.
  • Return ValueA result a function can hand back to whatever called it.
  • DecompositionBreaking a program into small, single-purpose functions.
  • Math.randomProduces an unpredictable value — useful for targets, dice, and surprises.
Quick recap Event — something the user does that runs code  ·  Variable — a named box that stores a value  ·  Conditional — code that runs only when a condition is true.
Trace It

Functions & Parameters

A function can take a parameter — an input — so the same block of code behaves differently depending on the argument you pass in. Read this carefully.

function updateScore(points) { score = score + points; setText("scoreLabel", score); } updateScore(10); updateScore(5);
What is the PARAMETER, and what ARGUMENTS are passed in the two calls?
After both calls (score started at 0), what is score?

Read the Code

This mini-app is decomposed: makeTarget() picks a secret number, and a parameterized checkGuess(guess, points) reuses it. Trace how the functions call each other.

var target = 0; function makeTarget() { target = randomNumber(1, 10); } function checkGuess(guess, points) { if (guess == target) { score = score + points; setText("msg", "Correct! +" + points); makeTarget(); } else { setText("msg", "Try again"); } } makeTarget(); onEvent("guessBtn", "click", function() { checkGuess(getNumber("guessInput"), 5); });
Which function CALLS another function (decomposition in action)?
What are the two parameters of checkGuess, and where are they used?
If checkGuess were defined AFTER the code that calls it, or its name were mistyped, what would happen?
