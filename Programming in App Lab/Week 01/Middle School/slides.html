Four Words

01
Design Mode
Where you place buttons, labels, images.
02
UI Element
A thing on screen.
03
Event
Something the user does — like a click.
04
Event Handler
The code that runs when it happens.

What Is App Lab?

A place to build real apps: drag elements onto a screen in Design Mode, then add JavaScript that reacts.
You drag a block; it writes the code.

Your First Event Handler

onEvent("button1", "click", function() {   setText("label1", "You clicked me!"); });
Click the button → the label changes.

Add a Button, Make It React

In App Lab: drag a button in Design Mode, then write a click handler. Watch it work.
Lesson 1 & 2 on Code.org.

More Buttons, More Reactions

onEvent("button2", "click", function() {   setImage("image1", "icon.png");   setText("label1", "Nice choice!"); });
Each button can do something different.

When It Doesn't Work

  • Does the element ID in the code match Design Mode EXACTLY?
  • Is the event type 'click'?
Mismatched IDs are the #1 beginner bug.

Build Your Reaction Screen

An About-Me screen, a soundboard, a mini pet, a hype-button — anything that reacts when someone clicks. Make it yours.
Plan it on paper first.

Plan First

  • What's your theme?
  • What elements will you add?
  • What does each button DO?
