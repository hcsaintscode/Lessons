Reference

Key Vocabulary

  • App LabA place to build real apps with drag-and-drop design plus JavaScript.
  • Design ModeWhere you place buttons, labels, and images on the screen.
  • UI ElementA thing on the screen — a button, label, or image.
  • EventSomething the user does, like a click.
  • Event HandlerThe code that runs when the event happens.
  • PropertyA feature of an element you can change — its text, color, or image.
Concept Check

Events = IOSP Live

Input → Processing → Output A click is the INPUT (something the user does). The event handler is the PROCESSING (the code that runs). The change on the screen is the OUTPUT (what the user sees happen). Every interactive app is just this loop, over and over.
