Variables · State

Think About It

  • A game shows your score going UP as you play.
  • Somewhere the app is remembering that number and changing it. How?
With a variable — a labeled box.

A Variable Is a Labeled Box

It has a NAME and holds a VALUE. You can put a value in, read it, or replace it.
var score = 0; → a box named score holding 0.

Three Things You Do With Variables

01
Declare
make the box: var score;
02
Assign
put a value in: score = 0;
03
Update
change it: score = score + 1;

score = score + 1

score = score + 1;
Read it right-to-left: take what's in the box, add 1, put it back.
This is how a score goes up.

Show the Value on Screen

setText("scoreLabel", score);
The label displays whatever's in the box right now.

Variables + Events = State

CLICK → UPDATE VARIABLE → SHOW NEW VALUE
The app REMEMBERS between clicks. That's state.

The Clicker Game

var score = 0; onEvent("clickBtn", "click", function() {   score = score + 1;   setText("scoreLabel", score); });
Click → score goes up → screen updates.

The #1 Variable Bug

If you declare var score = 0 INSIDE the handler, it resets to 0 every click.
Declare it ONCE, OUTSIDE the handler.

console.log Is Your Friend

console.log("score is", score);
Print the value to SEE what the app is really holding.
