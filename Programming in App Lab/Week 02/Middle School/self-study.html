Lesson 1

A Variable Is a Labeled Box

A variable is a labeled box that holds a value. It has two parts: a name (the label on the box) and a value (what's inside). You declare it once, put a value in, read the value when you need it, and replace the value whenever you want.

Declare — name the box

var score; creates a box labeled score. You do this once.

Assign — put a value in

score = 0; puts the value 0 into the box. The old value (if any) gets replaced.

Update — change what's inside

score = score + 1; takes the value out, adds 1, and puts the new value back.

That last line looks strange at first — it looks like math that can't be true. But it isn't math, it's an instruction, and you read it right to left: first take the value that's in score right now, then add 1 to it, then put that new value back into score. If the box held 4, it now holds 5.

Lesson 2

Variables + Events = State

Last week you learned about events — things the user does, like a click. This week you combine a variable with a click event. Every click runs a handler that updates the variable, and because the variable lives outside the handler, the app remembers its value between clicks.

A value your app remembers and can change over time is called state. A score, a count, a streak — those are all state. State is what makes an app feel like it's keeping track of you.

The demo on the right counts your clicks — the count is a variable that survives between clicks.

Here's the #1 bug to watch for: if you declare the variable inside the handler, it gets created fresh and reset to 0 on every single click — so it never counts up. The variable must be declared once, outside the handler.

Bug — resets every click
addBtn.addEventListener("click", function () {
  var count = 0;      // declared INSIDE — resets every time!
  count = count + 1;  // always ends at 1
});
Correct — remembers between clicks
var count = 0;        // declared ONCE, outside
addBtn.addEventListener("click", function () {
  count = count + 1;  // keeps going up: 1, 2, 3...
});

Make It Yours

Make It Yours

Now change the code on the right so the counter counts your way. You decide what it tracks and how it behaves:

  • Change what it counts: edit the <h1> label so it counts something real — like Glasses of water or Push-ups.
  • Count faster: change count = count + 1; to count = count + 2; so the button adds 2 each click.
  • Stretch: add a Subtract button that does count = count - 1; so you can count down too.
Stuck? Example edit

Make the +1 button add 2 instead by editing that line in index.js:

count = count + 2;

Add a Subtract button. First add it to index.html:

<button id="subBtn">-1</button>

Then give it its own handler in index.js:

document.getElementById("subBtn").addEventListener("click", function () {
  count = count - 1;
  display.textContent = count;
});

Same variable, one more event — now you can count up and down.

Reflect

Wrap-Up

The Big Idea

Variables give an app memory. A value you can change on events is called state — it's how a score, a count, or a streak works. Declare the variable once, update it when something happens, and show the new value. That's the pattern behind every counter in every app you use.
