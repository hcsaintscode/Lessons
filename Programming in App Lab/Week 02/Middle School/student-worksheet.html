Week 2 Student Worksheet · Programming in App Lab
Reference

Key Vocabulary

  • VariableA named box that stores a value.
  • DeclareMake the box: var score;
  • AssignPut a value in: score = 0;
  • UpdateChange it: score = score + 1;
  • StateThe values an app remembers and changes as it runs.
  • console.logPrints a value so you can check it while debugging.
Concept Check

The Labeled Box

Variable = a labeled box A variable is just a labeled box. It has a name (the label on the outside) and a value (what's inside). When you declare it you make the box, when you assign you drop a value in, and when you update you swap the value for a new one.
