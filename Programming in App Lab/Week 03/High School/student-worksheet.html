Reference

Key Vocabulary

  • Boolean ExpressionAn expression that evaluates to either true or false.
  • Comparison Operator==, !=, >, <, >=, <= — each compares two values and returns a Boolean.
  • Assignment vs Comparison= stores a value; == compares two values — never mix them in a condition.
  • if / if-elseRun code when a condition is true; the else runs otherwise.
  • if-else-ifA chain that picks among many outcomes — only the FIRST true branch runs.
  • Compound Condition&& both true, || either true, ! not.
  • ConcatenationJoining strings together with +.
Trace It

Evaluate the Boolean

A Boolean expression is a question the computer answers with true or false. Given the variables below, decide what each expression evaluates to.

var score = 80; var streak = 4;
Expression True or False?
score >= 80
score > 90
score >= 80 && streak >= 3
score > 90 || streak >= 3
Precision

Comparison vs Assignment

This is one of the most common bugs in every language. One symbol stores; two symbols compare. Getting them confused breaks your logic silently.

Explain the difference between = and ==, and what bug happens if you use = inside an if condition.
Trace It

Trace the Chain

In an if-else-if chain, only the FIRST true branch runs — the rest are skipped. The order of branches matters. Read this chain carefully; it has a bug hiding in its order.

if (minutes >= 30) { pick = "a movie"; } else if (minutes >= 120) { pick = "a double feature"; } else { pick = "a short video"; }
For minutes = 150, which branch runs — and which branch can NEVER run? Why?
How would you reorder the branches to fix it?
