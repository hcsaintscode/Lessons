Reference

Key Vocabulary

  • Input ElementA text box or dropdown the user fills in.
  • getTextReads what's in a text box or dropdown.
  • StringText data, written in quotes.
  • ConcatenationJoining strings with +.
  • if statementRuns code only when a condition is true.
  • if-elseTwo paths: one when true, one when false.
  • Comparison Operator== equals, > greater than, < less than.

Read the Code

This is an if-else in App Lab — the app gives different advice depending on the user's mood. Read it carefully, then answer the questions below.

var mood = getText("moodDropdown"); if (mood == "happy") { setText("advice", "Share it with a friend!"); } else { setText("advice", "Take a short walk."); }
If mood is happy, what shows? If it's anything else?
Why == and not = in the condition? Hint: one asks a question, the other puts a value in a box.
