Think About It

  • Your favorite apps feel personal — they use your name, your choices.
  • How does an app know what YOU typed or picked?
It reads your input.

Reading What the User Types

var name = getText("nameInput");
getText grabs whatever is in the text box.

Strings: Gluing Text Together

setText("output", "Hello, " + name + "!");
+ joins strings. That's called concatenation.

The Mad Lib

Read a few inputs, drop them into a silly sentence, show it back. Instant personalization.
Your first app that talks back.

The IF Statement

if (age >= 13) {   setText("msg", "You can sign up."); }
Run this code ONLY when the condition is true.

Comparing Values

  • == equals
  • > greater than
  • < less than
== compares. = assigns. Don't mix them up!

if-else: Two Paths

if (mood == "happy") {   setText("advice", "Share it with a friend!"); } else {   setText("advice", "Take a short walk."); }

Different Input, Different Output

INPUT → IF DECIDES → OUTPUT
The app chooses what to show based on YOU.

The #1 Decision Bug

= is ASSIGN. == is COMPARE. In a condition, always use ==.
If your app always does the same thing, check this first.

Build a Decision App

A personality quiz, a 'what should I eat/watch/wear' recommender, a mood-advice app — reads input, shows different output.
Plan the rules first.

Plan Your Rules

  • What input does it take?
  • What are the possible outputs?
  • What's the rule: if this → show that?
Start with 2 outcomes, then add more.
